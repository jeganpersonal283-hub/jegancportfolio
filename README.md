# Jeganathan C — 3D Professional Portfolio

A responsive, realistic, monochrome Cloud & DevOps portfolio with:
- Your supplied portrait in a circular hero frame on the right
- 3D particle background using Three.js
- Interactive 3D tilt effects on cards and portrait
- Floating cloud/devops/docker/linux chips
- Smooth reveal animations and scroll progress
- Responsive mobile navigation layout
- Projects limited to BusScanner, ATM Facial Recognition, and IoT Cloud Monitor
- Removed the requested AI assistance, ecommerce, real-time multiplayer, and AWS CI/CD deployment platform projects

## Run
No Node.js is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Internet access is recommended because Three.js and Google Fonts are loaded from CDNs.

For deployment, upload the folder to Netlify, GitHub Pages, Vercel, or any static hosting service.
